
# buzzer

`ESP32 C3 Super Mini` + `buzzer`. Простенькая пищалка, которая запускает случайную мелодию

Мелодии взяты из репозитория [arduino songs](https://github.com/robsoncouto/arduino-songs).

## Компоненты

- микроконтроллер
- buzzer
- npn транзистор
- светодиод
- резисторы 1kOm, 220om

## Сборка

Подключаем лампочку и пищалку через транзистор
